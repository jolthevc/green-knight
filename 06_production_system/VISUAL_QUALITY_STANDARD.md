# Visual Quality Standard

**Status:** Canonical portfolio-wide quality standard  
**Purpose:** Define the baseline visual threshold below which Green Knight should not publish, regardless of whether the production packet was technically followed.

---

## 1. Principle

A Green Knight video must look like a real media product.

It should not look like:

- a low-cost content farm
- generic AI video
- random stock assembly
- slideshow content
- a contractor template with a new logo

The viewer does not need to perceive the production as expensive.

The viewer should perceive it as intentional.

---

## 2. Quality Dimensions

Every finished video should be evaluated across seven dimensions.

### A. Specificity

Are visuals specific to the actual story?

### B. Coherence

Do footage, typography, graphics, motion, and music feel like one product?

### C. Clarity

Do visuals help viewers understand the narration?

### D. Taste

Does the piece demonstrate restraint, hierarchy, and judgment?

### E. Trust

Do visuals feel credible and appropriately sourced?

### F. Momentum

Does the visual experience sustain attention without becoming frantic?

### G. Brand Fit

Does this feel like the channel?

A video can be technically polished and still fail if it lacks these qualities.

---

## 3. Minimum Publish Threshold

Do not publish when any of the following materially defines the viewing experience:

- generic filler stock
- repeated irrelevant B-roll
- obvious AI artifacts
- illegible graphics
- inconsistent visual language
- amateur typography
- excessive template animation
- mismatched footage
- low-resolution imagery
- fake-looking documentary scenes
- visually unsupported factual claims
- jarring asset quality differences
- weak thumbnail execution
- edit pacing that makes good writing feel boring or chaotic

One imperfect shot does not fail a video.

A persistent low-quality visual pattern does.

---

## 4. Quality Hierarchy for Visual Sourcing

Where appropriate, prefer:

1. real specific evidence or footage
2. real specific photography / screenshots / documents
3. purpose-built graphics or diagrams
4. strong archival or licensed footage
5. tasteful context-specific stock
6. editorial illustration
7. AI-generated imagery when it genuinely improves the treatment
8. generic stock only when it still communicates effectively

This is guidance, not a rigid ranking.

A beautiful illustration can be better than mediocre real footage.

---

## 5. Consistency vs Repetition

Brand consistency is desirable.

Template repetition is not.

Reuse:

- type systems
- graphic language
- chart logic
- map language
- motion principles
- thumbnail philosophy

Do not reuse:

- the same transition everywhere
- the same composition every thumbnail
- the same stock montage structure
- the same AI aesthetic regardless of subject

The viewer should recognize the channel without predicting every visual choice.

---

## 6. AI Visual Quality Gate

Before using an AI-generated visual, ask:

1. Is it better than the available real or designed alternative?
2. Does it fit the channel?
3. Does it contain visible generation artifacts?
4. Could it mislead the viewer into thinking it is evidence?
5. Does it preserve factual details that matter?
6. Does it look intentional rather than cheap?
7. Is its style consistent with nearby visuals?

If the answer to the first question is no, do not use it.

---

## 7. Thumbnail Quality Gate

A thumbnail should generally pass:

- understandable in approximately one second
- clear focal point
- strong subject recognition where relevant
- minimal unnecessary elements
- readable on mobile
- visually coherent with the title
- sufficiently polished
- truthful
- distinct from generic category thumbnails
- consistent with channel identity

A thumbnail should not publish merely because it satisfies the original concept.

The execution must work.

---

## 8. The Zoom-Out Test

Before approval, view the thumbnail small.

Before approval, watch portions of the video without focusing on the narration.

Ask:

> Does this still look like a coherent professional media product?

This often exposes:

- clutter
- weak composition
- repetitive stock
- inconsistent typography
- low-quality imagery
- pacing problems

---

## 9. Reference Quality

Every channel should eventually maintain a small reference set demonstrating:

- target video quality
- target thumbnail quality
- acceptable graphics
- unacceptable graphics
- strong stock usage
- weak stock usage
- strong AI usage
- weak AI usage

These should live in the channel's `EXAMPLES.md`.

The portfolio standard defines the floor.

The channel examples define the specific aesthetic.

---

## 10. Quality Escalation

If an editor repeatedly misses the visual quality threshold:

1. improve the production packet if ambiguity is the problem
2. improve channel references if calibration is the problem
3. give direct revision feedback if execution is the problem
4. replace the editor if quality remains below standard

Do not endlessly compensate for weak editing by making production packets more prescriptive.

The operating system should support good talent, not attempt to simulate taste through exhaustive instructions.

---

## 11. Final Standard

Green Knight should publish fewer videos rather than knowingly lower the visual bar to maintain cadence.

The company is building owned media assets.

Each video should strengthen the perceived quality of the library.
