# Video Artifact Manifest

**Status:** Canonical portfolio-wide reference  
**Purpose:** Provide one compact map of the artifacts associated with a Green Knight video.

---

## 1. Canonical Development Artifacts

### 01 Video Brief
**Standard:** `VIDEO_BRIEF_STANDARD.md`  
**Purpose:** Define the editorial hypothesis and research mission.

### 02 Research Packet
**Standard:** `RESEARCH_PACKET_STANDARD.md`  
**Purpose:** Build the evidence base.

### 03 Source Log
**Standard:** `SOURCE_LOG_STANDARD.md`  
**Purpose:** Preserve factual traceability.

### 04 Outline
**Standard:** `OUTLINE_STANDARD.md`  
**Purpose:** Build the narrative architecture.

### 05 Script
**Standard:** `SCRIPT_STANDARD.md`  
**Purpose:** Produce final recordable narration.

### 06 Packaging Packet
**Standard:** `PACKAGING_PACKET_STANDARD.md`  
**Purpose:** Develop title-thumbnail promise and opening alignment.

### 07 Production Packet
**Standard:** `PRODUCTION_PACKET_STANDARD.md`  
**Purpose:** Translate editorial intent into visual production direction.

### 08 QA Record
**Standard:** `QA_STANDARD.md`  
**Purpose:** Verify the finished asset before publication.

### 09 Postmortem
**Standard:** `POSTMORTEM_STANDARD.md`  
**Purpose:** Convert performance into durable learning.

---

## 2. Supporting Production Files

Depending on the channel and video, Drive may also contain:

- narration audio
- pronunciation notes
- source documents
- downloaded licensed assets
- original graphics
- chart data
- map data
- thumbnail source file
- final thumbnail
- first cut
- revision exports
- project file
- captions
- final master
- platform export
- publishing metadata

These supporting files do not each require separate portfolio-wide standards unless recurring complexity justifies one.

---

## 3. Artifact Ownership

Every artifact belongs to the video's permanent `video_id`.

Titles can change.

Folder names can change.

The video ID should remain stable.

---

## 4. Canonical vs Working

A video may contain many working files.

The system should distinguish between:

- current canonical approved artifact
- superseded version
- temporary working material
- final published asset

n8n should reference canonical artifacts wherever possible.

---

## 5. Minimum Viable Artifact Set

A standard long-form Green Knight video should normally not reach publication without:

- approved brief
- research packet
- source log
- approved outline
- approved script
- packaging packet
- production packet
- QA result
- final video
- final thumbnail
- post-publication performance record
- eventual postmortem

Exceptions should be intentional and documented.
