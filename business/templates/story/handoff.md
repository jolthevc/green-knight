# Editor handoff

Template: replace all placeholders before sending. This file is not an instruction to send a message automatically.

## Concept and style
Channel, chosen question, one-sentence promise and links to approved style direction.

## Locked inputs
script.txt version; cue sidecar; visual plan; source/claim map; title/thumbnail recommendation. The clean script is the only spoken-text source.

## Voice
Provider/voice/settings if selected; otherwise request a 30–45 second audition before full generation. Record pronunciation guidance and supported cue implementation. Never paste sidecar JSON into TTS as narration.

## Production scope and quote
Confirm video length 8–10 minutes; editing, imagery/motion, voiceover, thumbnail, captions, metadata, revisions and editable assets as individually agreed. Record pilot price and 10-video package quote separately. Do not assume an earlier full-service package covers the reduced production-only job.

## Visual direction
Warm ink illustration, selective explanatory movement and verified evidence inserts. Invite the editor to challenge costly or unclear choices and propose sustainable equivalents. Preserve the core identity.

## Delivery and acceptance
Review cut; agreed asset formats/resolution; clean voice track; metadata; thumbnail; captions/project files if commissioned; revision rounds and dates as agreed. Actual finished runtime must be 480–600 seconds.

Check script fidelity, no spoken directions, pronunciation, clear voice/music balance, factual labels, readable visuals and package alignment. Substantive script/fact changes return to editorial. Final publication remains a separate owner action unless expressly delegated.
