# Quality and approval record

Template: unchecked items are not passed checks.

## Editorial
- [ ] Selected promise and channel lane are clear.
- [ ] Research tests the hypothesis and strongest counterargument.
- [ ] Important claims, numbers, quotes and causality trace to opened sources.
- [ ] Script is complete, clean spoken text and original to this episode.
- [ ] Opening matches packaging and provides an early useful answer.
- [ ] Every beat advances evidence, understanding or stakes.
- [ ] All open promises pay off; no misleading suspense or filler.
- [ ] Closing gives the answer and one appropriate CTA.
- [ ] Paragraph cue/claim/visual anchors match the latest script version.
- [ ] Word count and explicit timing assumptions are recorded.
- [ ] Repository validator passes.

## Production
- [ ] Owner-selected voice audition/settings recorded.
- [ ] No stage directions or citation IDs spoken.
- [ ] Numbers, names, pronunciation and pacing checked.
- [ ] Illustrations/documents/chart labels accurately represent evidence.
- [ ] Rights/permissions for actual assets recorded where relevant.
- [ ] Captions, small-screen readability and sound mix checked.
- [ ] Actual rendered runtime is 480–600 seconds.
- [ ] Final title/thumbnail/opening/closing align.
- [ ] Final chapter times and real end-screen links verified.
