# Pretty Penny

**Promise:** Understand the money machine behind something familiar.

**Format:** 8–10 minute narrated illustrated business/economics stories for curious adults. Familiar objects, unexpected incentives, a clear mechanism and a concrete payoff.

## Working decisions

Name and runtime are set. The warm ink-illustration palette and typography are a proposed production direction drawn from the discussion, ready for an editor's feasibility feedback and pilot. The final narrator, provider, pricing, schedule and production assets are not selected.

Generate an idea batch first; the owner chooses the first actual episode. The stories directory currently contains instructions, not completed stories.
