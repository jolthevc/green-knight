# Hard Costs repeatable infographic and archival design
A sustainable production system between Modern MBA realism and economic infographic explainers. Reuse well-designed components with episode-specific logic, not entire interchangeable videos.

1. **Payments waterfall:** owner/lender -> GC -> trade -> supplier/workers; cash versus invoices, holdbacks and delays.
2. **One-crew P&L:** staff/hours x utilization x priced jobs -> revenue -> labor/materials/overhead -> contribution and cash.
3. **Cost/margin bridge:** bid price, direct costs, labor, equipment, contingency, change orders, cash and risk.
4. **Growth map:** one truck -> dispatcher -> crews -> branch -> region/M&A, with financing/management capacity at each move.
5. **Equipment utilization:** earning vs idle hours, maintenance, lease/debt and residual values.
6. **Construction supply chain:** quarry/factory -> transport -> distributor -> site -> installation, with weight/time effects.
7. **The contract:** proposal -> scope -> field issue -> documented change -> approval -> payment.
8. **Timeline/evidence:** genuine dates, records and historical photography; distinguish illustration from original source.
9. **Decision comparison:** source-based two operating approaches using comparable denominator, geography and period.
10. **Infrastructure/bottleneck map:** utility access, permit boundary, land parcel, route, service capacity and outcomes.

**Sample storyboard:** a plumbing operator's documented growth story opens in a real van or jobsite, explains one initial paid unit, uses an *explicitly illustrative* crew/revenue equation, returns to sourced company footage/records, then evolves the visual from crews to branch/region with new dispatch, cash and workforce costs. Finish with documented decisions and what would fail for a different owner.

Editor should implement the director's chosen shots and transformations affordably using documentary assets, 2D diagrams, maps and restrained motion. Re-check archival/footage rights; no fabricated documentary evidence. This is a brief, **not** an approved asset/template library.
