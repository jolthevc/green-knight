# Green Knight Entertainment

Independent entertainment-documentary channels under the Green Knight portfolio.

Current channel:
- [Internet Famous](internet-famous/README.md): how internet fame and virality actually work, told through compelling, fact-based stories.

This is a distinct manual editorial workspace. It lives within the existing Green Knight GitHub repository. It has not been enrolled in the legacy automated channel registry or publishing system. Do not claim that a new standalone GitHub repository, producer engagement, voice audition or video release exists.

General governing principles from [Green Knight's popcorn standard](../business/POPCORN_STANDARD.md) apply: entertainment earns the next minute, newcomers can follow, informed viewers learn a real mechanism, and facts are non-negotiable. The explicit Internet Famous rules override the business workspace's 8-10 minute duration.
