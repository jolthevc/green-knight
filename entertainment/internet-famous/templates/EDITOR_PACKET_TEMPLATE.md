# Template: EXACTLY three editor-facing documents

**NOT a released packet.** Make a separate per-episode editor-packet folder ONLY after fact review, integrated QA, approved full script and selected/approved voice. The three files are below.

## 01_SCRIPT.txt
File first line: TITLE: [one owner-approved final title]
Then one blank line, then spoken narration only. No act markers, IDs, sources, brackets or performance instructions. Number speech paragraphs internally P001 onward by blank lines; P labels do not appear in file.

## 02_NARRATION_DIRECTOR.md
Header: episode ID, script version and hash, approved voice profile/reference, target measured range, exact title.

START WITH:
- NON-SPOKEN performance overview and pronunciation entries.
- S00 COLD OPEN | approximate 0:00-0:30 | P001-P00x | Intent: immediate curiosity, restrained urgency | Pauses/words needing emphasis | Transition to S01.
- SPOKEN COPY: [VERBATIM P001... body]
Repeat section for S01 SETUP, S02 FUSE, S03 AMPLIFIER, S04 PRICE/MIDDLE, S05 REVERSAL, S06 REVEAL, S07 CLOSER.

For every segment: exact paragraph range, why story is moving, conversational pace and tone, deliberate beats/silence, clean pronunciation. Make ALL guidance plainly 'NOT SPOKEN'. The spoken copy concatenated across S00-S07 must EXACTLY equal clean 01.

## 03_VISUAL_DIRECTOR.md
Header: episode ID, script hash, one selected title + thumbnail + exact first frame.
- S00 COLD OPEN shot-by-shot 0-30s aligned to exact P### beats, what starts/changes/ends and the evidence/artifact used.
- S01 SETUP -> ... -> S07 CLOSER each with P### spans, 1-3 scene concepts, exact authentic screen text, image transformations, source/rights status, precise emotional purpose, music and breathing points.
- The big S04 middle revelation must get a purposeful visual change.
- Show recurring visual motif and end callback to first frame.
- Deliver production list of assets and non-negotiable missing asset alternatives.
- No synthetic evidence posing as genuine documents.

## Hard release requirements
ONE approved title, ONE thumbnail direction, ONE first frame, ONE visual plan. Final script/02 spoken text match exactly; all P### and S## references align with 03. Selected and approved voice. Fact/rights review complete. Owner approval. All three docs pass independent and integrated QA. Nothing else is placed in final editor-packet/.
