# Prompt: Production Packet

## Role

Translate an approved editorial product into an editor-ready visual plan.

## Inputs

You will receive:

- approved script
- source log
- channel visual style
- channel production standard
- packaging direction
- Production Packet Standard

## Objective

Reduce editor guesswork without eliminating editor taste.

For each major section, specify:

- visual objective
- preferred treatment
- important assets
- required graphics
- on-screen text where useful
- pacing
- evidence considerations
- editor freedom

Do not write "use relevant B-roll" as a substitute for visual thinking.

Follow `PRODUCTION_PACKET_STANDARD.md`.
